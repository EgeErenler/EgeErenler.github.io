# egeerenler.github.io

Personal portfolio website of Ege Erenler, software engineer and data scientist based in London.

A single static page (`index.html`) with no build step. Served by GitHub Pages.

## Edit the contact details and photo

Open `index.html` and fill in the `PROFILE` block near the bottom:

```js
const PROFILE = {
  email: "",
  linkedin: "",
  photo: ""
};
```
